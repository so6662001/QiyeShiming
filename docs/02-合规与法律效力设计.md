# 钢贸提货单实名签收系统 · 合规与法律效力设计

> 本文聚焦：如何让"提货确认/出库交付/结算确认"具备法律效力，以及个人信息合规要点。

---

## 1. 法律效力的总体逻辑

法院在纠纷中真正审查的是三件事，分别由不同机制解决：

| 法律问题 | 解决机制 | 说明 |
|---|---|---|
| 签字的是不是真实的人 | 个人实名认证 | 一次性，可复用 |
| 签署有没有法律效力 | 可靠电子签名（CA 证书 + 时间戳 + 防篡改存证） | 决定效力的核心 |
| 是不是本人真实意愿 | 签署意愿认证（短信/人脸/密码） | 每次操作 |
| 行为是否约束买方企业 | 合同预授权 + 职务/委托代理 + 提货码授权链 | 把个人/司机行为绑定到企业 |

> 关键结论：**企业实名认证不是法律效力的必要条件**，它主要用于风控。法律效力来自"个人可靠电子签名 + 授权关系证明"。

---

## 2. 可靠电子签名的法定要件

依据《中华人民共和国电子签名法》第十三条，"可靠的电子签名"与手写签名或盖章具有同等法律效力，须同时满足：

1. 电子签名制作数据用于电子签名时，**属于电子签名人专有**；
2. 签署时电子签名制作数据**仅由电子签名人控制**；
3. 签署后对电子签名的**任何改动能够被发现**；
4. 签署后对数据电文内容和形式的**任何改动能够被发现**。

### 落地要求

| 要件 | 实现方式 |
|---|---|
| 专有 + 控制 | 经办人个人实名 + 个人数字证书 + 签署时意愿认证（短信/人脸） |
| 防篡改（签名） | 由具备资质的 CA 机构（持工信部《电子认证服务许可证》）签发数字证书 |
| 防篡改（内容） | 文件哈希 + 可信时间戳 + 区块链/哈希存证 |
| 时间不可抵赖 | 可信时间戳（如联合信任时间戳服务中心 TSA） |

> ⚠️ **不要自建 CA**。无资质的电子签名在法律上效力存疑。应接入持牌 CA 或第三方电子签平台。

## 3. 三个核心法律时点的依据

### 3.1 经办人发起提货指令 —— 授权成立

- **机制**：买方实名经办人在线签署"授权某车牌/司机本次提取 XX 数量"的提货指令。
- **法律支撑**：
  - 合同预授权条款（见 `04` 文档）；
  - 《民法典》第170条 **职务代理**：执行法人或非法人组织工作任务的人员，就其职权范围内事项以单位名义实施的行为，对单位发生效力；
  - 《民法典》第172条 **表见代理**：相对人有理由相信行为人有代理权的，代理行为有效。

### 3.2 货物驶离仓库 —— 交付完成与风险转移

- **机制**："出库即确认"，货物经过磅、出库、驶离仓库时交付完成。
- **法律支撑**：
  - 《民法典》第604条：标的物毁损、灭失的风险，**交付前由出卖人承担，交付后由买受人承担**；
  - 买方自提场景下，交付地点在卖方处所，买方（或其授权司机）提走货物即完成交付；
  - 合同"自提交付与风险转移"条款明确约定该时点。

### 3.3 结算单送达后 T+N 无异议 —— 数量金额最终确认

- **机制**：结算单送达买方，约定期内无书面异议即视为认可数量与金额。
- **法律支撑**：
  - 《民法典》第140条第2款：**沉默只有在有法律规定、当事人约定或符合交易习惯时，才视为意思表示**——因此必须有合同约定；
  - 《民法典》第621条：**约定检验期间的，买受人在检验期间内未通知数量/质量不符的，视为符合约定**——这是"结算单 + 异议期"的直接法律依据。

#### 成立的三个前提（缺一不可）

1. **合同明确约定**异议期与沉默后果；
2. **结算单送达可举证**（系统推送日志、已读回执、短信/邮件发送记录）；
3. **异议期合理**（建议 ≥ 2~3 个工作日，避免被认定过短不合理）。

## 4. 第三方驾驶员授权链的合规设计

### 4.1 风险

第三方司机与买方无劳动关系，其提货行为不必然约束买方，买方可能抗辩"非我员工、未授权"。

### 4.2 合规闭环

```
实名经办人 (合同预授权)
   └─ 在线签署提货指令，生成一次性提货码（绑定车牌/数量/时段）
        └─ 提货码 = 买方对本次司机提货的具体授权凭证
             └─ 仓库核验提货码 + 车牌 → 放行
                  └─ 买方不得否认（合同"驾驶员代提授权"条款）
```

- 实名分量由经办人承担，司机端可免实名；
- 提货码是"一次一授权"的具体化，证明买方对该次提货的明确授权；
- 合同"驾驶员代提授权"条款排除买方"非员工/未授权"抗辩。

## 5. 证据链合规要求

每次提货须自动归集并存证以下证据（详见 `05` 文档）：

1. 经办人实名提货指令（电子签名 + 时间戳）；
2. 提货码核验记录；
3. 车牌识别抓拍；
4. 过磅单/磅码单（毛重/皮重/净重 + 时间）；
5. 出库单；
6. 闸口/磅房视频或照片；
7. 出库时间戳 + 区块链/哈希存证；
8. 结算单送达记录与异议期记录。

存证要求：原始数据哈希上链或写入可信存证机构，确保事后**不可篡改、可验证、可出证**（司法鉴定/公证报告）。

## 6. 个人信息保护合规（《个人信息保护法》PIPL）

实名认证、人脸识别涉及敏感个人信息，须满足：

| 要求 | 落地 |
|---|---|
| 告知—同意 | 实名/人脸前弹出独立授权同意，明确收集目的、范围、保存期限 |
| 最小必要 | 仅收集核验所需的姓名、身份证号、手机号、人脸特征 |
| 单独同意 | 人脸等敏感信息须单独勾选同意 |
| 加密存储 | 身份证号、人脸数据加密；人脸特征建议不落地或脱敏存储 |
| 委托处理协议 | 与第三方实名/电子签服务商签订数据处理协议（DPA） |
| 出境合规 | 数据不出境；如用境外服务需评估（一般不涉及） |

> 配套文本见 `04` 文档中的《个人信息处理授权同意》。

## 7. 合规检查清单（上线前自查）

- [ ] 接入可信时间戳服务
- [ ] 接入区块链/哈希存证，支持出具存证报告
- [ ] 购销合同含：预授权、自提交付与风险转移、驾驶员代提授权、结算异议期四类条款
- [ ] 结算单送达具备可举证机制
- [ ] 异议期设置合理（≥ 2~3 个工作日）
- [ ] 实名/人脸前有合规告知同意，敏感信息单独同意
- [ ] 与服务商签订数据处理协议（DPA）
- [ ] 个人敏感信息加密存储、最小必要

# 钢贸提货单实名签收系统 · 完整设计方案

本目录为面向钢贸企业的「提货单实名签收程序」完整设计方案，覆盖业务、合规、产品、法律文本、技术与成本。

## 场景一句话

钢贸客户安排驾驶员上门提货，**经办人（采购员/老板）线上实名发起提货指令并生成提货码**，驾驶员凭码到仓提货，**货物驶离仓库即视为交付确认**，事后结算单送达、异议期内无异议即确认数量金额。全程电子签名 + 时间戳 + 存证，确保法律效力，并严格控制实名成本。

## 三大设计要点

1. **实名与法律效力分离**：实名（一次性、≤0.5 元）解决"你是谁"；法律效力靠"可靠电子签名 + 时间戳 + 存证"。
2. **实名放在经办人、执行交给提货码**：经办人实名下指令生成提货码，驾驶员凭码提货，把第三方司机的提货行为牢牢绑回实名经办人。
3. **企业实名做减法**：用《购销合同》预授权条款替代繁琐企业实名，企业资料由业务员后台代办，客户端无感。

## 三个法律时点

| 时点 | 法律意义 | 依据 |
|---|---|---|
| 经办人发起提货指令 | 授权成立 | 合同预授权 + 可靠电子签名 + 职务/表见代理 |
| 货物驶离仓库 | 交付完成、风险转移 | 《民法典》第604条 + 自提交付条款 |
| 结算单送达后 T+N 无异议 | 数量金额最终确认 | 《民法典》第621条 + 异议期条款 |

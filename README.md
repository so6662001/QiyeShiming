# QiyeShiming · 钢贸提货单实名签收系统

企业实名制及员工实名 —— 面向钢贸企业的提货单实名签收解决方案。

客户安排驾驶员上门提货，经办人（采购员/老板）线上实名发起提货指令并生成提货码，驾驶员凭码到仓提货，货物驶离仓库即视为交付确认；事后结算单送达、异议期内无异议即确认数量金额。全程电子签名 + 时间戳 + 存证，确保法律效力，并严格控制实名成本（企业/员工实名各 ≤ 0.5 元）。
